# Data

## Role

Persist authored root-Testing verification bindings consumed by Certification and replayable cross-Module regression fixture authority.

## Origin

The root Testing Module authors bindings only for verification obligations owned by the root Fortress Feature. Regression fixtures are test inputs and independently authored expected outcomes, never production permissions or Certification evidence.

## Semantics

Bindings map current semantic obligation identities to exact parent-local Test IDs without asserting that execution occurred or passed. The qualification corpus fixes source, Cargo, governance, context, and oracle bytes for bounded regression replay; the ledger records raw result hashes and honest unreproduced or unsupported cases.

## Validity

Every obligation and Test ID must exist, remain canonically sorted, and belong to this Testing boundary. Corpus records validate their exact byte counts and digests before replay. Representative public upstream tags are excluded from historical scoring while original policy and mutation bytes are unavailable.

## Lifecycle

Bindings change when current generated obligation identity or the truthful parent-local verification evidence changes. Corpus oracle changes require explicit adjudication; result hashes change when an accepted producer semantic version or output changes.

## Files

### [`Cargo.toml`](../_data/Cargo.toml)

Defines the test-owned qualification binary and its declared Engine and independent reference-library dependencies. Native package imports preserve Module boundaries without adding a production dependency on Testing.

### [`verification_bindings.json`](../_data/verification_bindings.json)

Binds root Fortress audit-Feature verification obligations to its exact audit-flow test.

### [`qualification_cases.json`](../_data/qualification_cases.json)

Pins three positive workload shapes and four negative controls with exact source and governance bytes, context, mutation status, expected claims and findings, plus three public representative Git revisions that are explicitly not historical reproductions.

### [`regression_ledger.json`](../_data/regression_ledger.json)

Records case output hashes, distinct source site counts separately from propagated path counts, fixed controls, unsupported boundaries, pending dependent work, and the unreproduced original population.

Current raw output pins were reviewed after replay with semantic-conformance producer 5.1.0 and State/Effect schema v5. The seven authored controls retain their source, policy, expected verdict, finding-count, and historical-reproduction oracles. New output identities bind the installed operation catalog and explicit summary opacity; successful negative results also bind their complete proof premises. An observed external effect remains a positive witness without becoming a complete effect upper bound.

### [`semantic_qualification_protocol.json`](../_data/semantic_qualification_protocol.json)

Preregistered deterministic automated protocol over 86 cases, 76 required controls, 28 held-out selections and 384 source replacements among 64 cases. Exact original freeze hashes, independent provenance, all unsupported denominators and nonvacuity are mandatory. Human adjudication and population accuracy remain future unqualified research; performance is outside the verdict.

### [`supported_scope_manifest.json`](../_data/supported_scope_manifest.json)

Predeclares filesystem.write/process.spawn and exact supported/unsupported strata without promoting defaults or claiming general control/data-flow qualification. Standard Registry consumes caller-provided metadata without importing these test expectations.

### [`semantic_oracle_provenance.json`](../_data/semantic_oracle_provenance.json)

Pins independent primitive semantics and original-source reasoning to Rust 1.97.1 release commit and Git blob/content identities. Compiler syntax evidence is distinct from effect truth and runtime execution; no Fortress conclusion supplies an expected answer.

### [`synthetic_scopes_freeze.json`](../_data/synthetic_scopes_freeze.json)

Original pre-evaluation 82-case byte-preserved freeze: 64 restricted-language cases plus authorization, undeclared, zero-coverage, malformed, macro and unknown-configuration controls. Expected outcomes and held-out selection preceded native scoring.

### [`na_scopes_addendum.json`](../_data/na_scopes_addendum.json)

Two separately preregistered data-only nonapplicable controls, preserving the original 82 cases. No empty Rust source or invented library target is substituted; nonapplicability does not discharge evaluability.

### [`public_scopes_freeze.json`](../_data/public_scopes_freeze.json)

Two exact-SHA original public file scopes from ripgrep and Serde with original paths, bytes, MIT notices and independent API/language reasoning. One real spawn witness is required; arbitrary Iterator behavior remains uncertain. Research wrappers do not certify whole upstream repositories or original builds.

### [`source_mutation_relations.json`](../_data/source_mutation_relations.json)

All 384 directed one-opcode replacements among 64 frozen cases, including 208 reporting and 72 enforcement contrasts. Endpoint expectations are independent; these edges are not extra independent samples.

### [`primitive_profile_inputs.json`](../_data/primitive_profile_inputs.json)

Explicit accepted research premises for exact frozen literal-borrow and fresh-command synthetic sources, expressed through the existing assumed-summary contract. These condition cross-effect negatives; they are not certified Standard-library bounds. The driver retains the unconfigured uncertainty and assumption references. Public scopes and arbitrary user code cannot receive these premises.
