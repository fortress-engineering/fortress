# Modules

## Composition

Implementation Observation separates its source analyzer from parent-local verification so fixtures and assertions cannot become observed repository authority.

## Modules

### [Implementation Observation Testing](../mods/testing/README.md)

Verifies snapshot integrity, Rust reference resolution, ownership, facade preservation, normalization, unsupported coverage, and deterministic output for the Feature introduced by this parent.

## Coordination

The Testing child supplies synthetic snapshot-bound source ecosystems to the public analyzer while this parent exclusively owns observation facts and analyzer semantics.
