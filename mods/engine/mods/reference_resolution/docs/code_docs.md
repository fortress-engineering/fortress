# Code

## Role

The Code owns deterministic stable-identity resolution, understood reference classification, physical-boundary inventory, projection reconciliation, semantic delta, and relocation-preview semantics.

## Execution

The resolver consumes one immutable CCG and exact snapshot file map, indexes governed Module identity and current location, structurally parses only understood Markdown, Cargo, registry, and Rust reference forms, and emits one canonical location projection plus normalized rule findings.

## State

All indexes and simulations are process-local and derived from immutable inputs; no authored component inventory or relocation history is retained.

## Failure Semantics

Malformed understood inputs return typed errors, while machine-local persistence, stale navigation, unregistered cross-Module traversal, and identity/location disagreement become deterministic REPO-REFERENCE-001 findings. Unsupported language ecosystems remain outside the claimed evaluator boundary.
