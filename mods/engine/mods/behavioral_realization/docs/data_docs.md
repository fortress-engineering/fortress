# Data

## Role

The Module owns schemas and normative rule Data governing authored checkpoint realization authority and derived Realized BFG semantics.

## Origin

Maintainers author the schemas and draft rule records; distributed realization contracts are authored by their owning Modules, while Realized BFG output remains derived root Info.

## Semantics

The contract schema defines exact checkpoint-to-semantic-anchor bindings, the graph schema defines coverage-aware realized Feature conclusions, and two rules separate general realization coherence from proven dominator bypasses.

## Validity

Every Data file is canonical JSON, schema-valid, registered exactly once, and uses a closed semantic anchor vocabulary rather than arbitrary prose or source-name inference.

## Lifecycle

Schema and rule changes are reviewed with analyzer semantics and parent-local evidence; superseded representations remain only in Git history.
