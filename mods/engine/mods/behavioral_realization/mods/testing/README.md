## Purpose

Behavioral Realization Testing exists to prove the checkpoint realization, edge reconciliation, and dominator-bypass semantics introduced directly by its parent Module.

This Module supplies parent-local evidence for contract validation, semantic anchor resolution, event reachability, checkpoint and Feature states, next meaningful transitions, bypass freedom coverage, deterministic Realized BFG output, and live Fortress audit-Feature realization.

It includes exact positive and negative identity checks, all five anchor domains, helper suppression, branching, terminals, dominators, loops, uncertainty, verification obligations, canonical bytes, digest identity, and live repository integration.

### Excludes

It excludes production capability ownership, source parsing, runtime tracing, automatic anchor generation, capability realization, presentation, evidence certification, and foreign Feature verification.
