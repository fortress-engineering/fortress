# Modules

## Composition

Affected Analysis delegates deterministic graph, cache, and stress verification to one parent-local Testing Module while retaining production invalidation authority here.

## Modules

### [Affected Analysis Testing](../mods/testing/README.md)

Verifies change classification, conservative transitive invalidation, narrow contract and governance impact, verified cache states, byte identity, relocation independence, and large-graph performance.

## Coordination

Testing consumes the Engine and Affected Analysis public boundaries and contributes stable verification identities to the existing Contract Coherency Graph.
