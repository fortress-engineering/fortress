# Code

## Role

The Code verifies the complete universal Source Architecture contract using synthetic language shapes and the live Fortress source inventory.

## Execution

Tests construct canonical Project Filing and CCG fixtures, reuse documentation responsibilities, feed language-neutral observations, evaluate profile compositions, compare canonical bytes, and stress ten thousand artifacts without parsing real language syntax.

## State

All fixtures are deterministic in-memory values or bounded temporary repositories and retain no state between tests.

## Failure Semantics

Negative cases assert typed profile errors or exact Source Architecture conclusion kinds; unsupported observation remains explicit and never becomes favorable absence.
