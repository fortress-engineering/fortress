Nominal/type-oriented, functional/module, and script/orchestration synthetic profiles; generated source; negative normalized conclusions; live Fortress inventory; and ten-thousand-artifact stress.

Production Rust archetype definitions, Rust ordering or naming rules, source rewriting, deep program correctness, and hosted execution of long local certification gates.
