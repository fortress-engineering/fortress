# Modules

## Composition

Source Architecture delegates conformance verification to one parent-local Testing Module while retaining all production semantic authority here.

## Modules

### [Source Architecture Testing](../mods/testing/README.md)

Verifies universal profile neutrality, artifact identity and coverage semantics, generated-source handling, deterministic projection, PSM reference reuse, relocation behavior, and large-corpus scale.

## Coordination

Testing consumes the Engine and Source Architecture public boundaries and supplies stable test identities to the existing CCG traceability topology.
