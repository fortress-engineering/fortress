# Code

## Role

The Code owns the universal source-region vocabulary, Source Profile and archetype model, deterministic Source Artifact compiler, PSM reference projection, structural evaluation, and shared Finding Model integration.

## Execution

The compiler consumes Project Filing inventory, CCG ownership, canonical `code_docs.md` responsibilities, exact bytes, optional adapter observations, and stable semantic references; it never parses language syntax or Markdown.

## State

All registries, indexes, artifact conclusions, and summary counts are process-local deterministic derivations from immutable inputs.

## Failure Semantics

Invalid profile authority returns typed errors, while missing responsibility, unavailable required observation, unresolved archetype, forbidden composition, and missing generator identity become normalized rule findings only when applicable.

## Files

### [`source.rs`](../code/source.rs)

Defines Source Artifact Model v1, universal semantic regions and coverage, Source Profile/archetype contracts, generated and verification provenance, lightweight PSM projections, deterministic compilation, and SOURCE-PROFILE-001/SOURCE-ARTIFACT-001 evaluation.
