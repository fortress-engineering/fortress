# Modules

## Composition

Behavioral Semantics separates production compilation from parent-local verification so graph algorithms and normative behavior findings can evolve behind one durable capability boundary.

## Modules

### [Behavioral Semantics Testing](../mods/testing/README.md)

Verifies only the Intended BFG and BEHAVIOR-FLOW-001 Feature introduced by Behavioral Semantics, including positive, negative, boundary, determinism, provenance, and live self-application cases.

## Coordination

The parent owns production behavioral semantics, while its Testing child proves those semantics through canonical CCG fixtures and the live Fortress audit Feature without claiming responsibilities owned by Contract Coherency or Snapshot Governance.
