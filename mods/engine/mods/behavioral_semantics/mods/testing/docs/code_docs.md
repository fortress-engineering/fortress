# Code

## Role

Provide parent-local executable evidence for deterministic Intended BFG compilation and modeled-flow coherence semantics.

## Execution

Cargo runs the explicit Behavioral Semantics integration target, which constructs canonical Contract v2 repositories, compiles their CCGs and BFGs, asserts exact graph facts and failures, and compares the live derived artifact with freshly generated bytes.

## State

Tests use isolated temporary repositories and process-local graph values; no persistent state is mutated.

## Failure Semantics

Any schema, contract, CCG, graph, provenance, modeling-state, determinism, freshness, or expected-finding mismatch fails the owning test with its stable Test ID and requirement marker.

## Files

### [`behavioral_flow.rs`](../code/behavioral_flow.rs)

Exercises canonical BFG construction, graph algorithms, distributed ownership, exact contradictions, deterministic serialization, provenance, unmodeled behavior, and live Fortress self-application.
