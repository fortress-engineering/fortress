# Code

## Role

Provide parent-local executable evidence for deterministic Intended BFG compilation and modeled-flow coherence semantics.

## Execution

Cargo runs the explicit Behavioral Semantics integration target, which constructs canonical Contract v2 repositories, compiles their CCGs and BFGs, and asserts exact graph facts and failures. Live compilation repeats independently for exact canonical-byte equality. Any selected local-quality BFG is resolved through its exact context selection and strict immutable manifest, then checked against its member digest, byte count, supported layout identity, and CCG binding. Intact prior-source evidence is classified as stale before consulting the current layout registry, whose bytes may have changed with the source. Current-source evidence must match the registered layout digest; exact current-source and current-layout selections must equal the freshly generated bytes. Retained evidence never certifies the candidate source.

## State

Tests use isolated temporary repositories and process-local graph values; no persistent state is mutated.

## Failure Semantics

Any schema, contract, CCG, graph, provenance, modeling-state, determinism, freshness, or expected-finding mismatch fails the owning test with its stable Test ID and requirement marker.

## Files

### [`behavioral_flow.rs`](../_code/behavioral_flow.rs)

Exercises canonical BFG construction, graph algorithms, distributed ownership, exact contradictions, deterministic serialization, provenance, unmodeled behavior, and live Fortress self-application. Subject controls reject different current bytes, corrupted or truncated members, unsafe member locators, and incorrect layout digests while preserving explicit stale-source and retained-layout distinctions. The final issuer remains responsible for requiring a current exact-source generation.
