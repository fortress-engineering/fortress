# Modules

## Composition

Finding Model separates provider-independent production representations from the direct Testing Module that verifies their shared proof contract.

## Modules

### [Finding Model Testing](../testing/README.md)

Verifies canonical evidence references and proof graph structure without judging claim truth or producer trust.

## Coordination

Production Code owns findings, defeaters, governance authority, and proof shape. Testing exercises those boundaries through the public engine facade and introduces no second evaluator or identity authority.
