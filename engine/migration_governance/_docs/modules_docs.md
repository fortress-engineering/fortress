# Modules

## Composition

Migration Governance owns one transaction engine and delegates its acceptance controls to its Testing Module.

## Modules

### [Migration Governance Testing](../testing/README.md)

Qualifies exact operation graphs, read-only preview, source-bound authorization consumption, interrupted application, actual-target validation and conflict-preserving recovery.

## Coordination

Testing consumes the public Engine facade and established canonical adapters. Production code imports no test oracle or synthetic approval validator.
