# Data

## Role

Define the wire contract for scoped native dependency projections.

## Origin

The Implementation Observation Module owns this schema and its existing
source-level evidence vocabulary.

## Semantics

The projection links exact import or reference sites to admitted package and
file endpoints. The scope preserves ownership uncertainty and conditionality.

## Validity

The writer bounds source bytes and output rows, verifies each admitted file
digest, and constructs observations from the selected native receipt.

## Lifecycle

The compatibility catalog identifies the writer and schema version for
historical inspection.

## Files

### [`native_dependency_schema_v1.json`](../_data/native_dependency_schema_v1.json)

Defines the subordinate Go and Python projection. Its positive scope is limited
to observed source relationships under the exact bound native and ownership
inputs. Runtime reachability, completeness and assessment are unestablished.
