# Data

## Role

Retain independently specified protocol fixtures for external evidence normalization and replay.

## Origin

Fortress maintainers author XML and SARIF controls from public format semantics and explicit conservative protocol rules before native CLI comparison. Expected outcomes are not copied from Fortress-generated judgments.

## Semantics

Each case supplies original bytes, optional synthetic companion premises and a complete literal expected normalized record or explicit refusal. Synthetic metadata never claims genuine external execution or independent human adjudication.

## Validity

Frozen source identities, exact expected output and the independent standard-library consumer must agree. Sampling is deterministic adversarial coverage; population precision, false-positive estimates and confidence intervals are unavailable.

## Lifecycle

Retain earlier freezes and explicit corrections. Revise expected semantics only from independent evidence and retain previous results; observed native output is never its own validation oracle.
