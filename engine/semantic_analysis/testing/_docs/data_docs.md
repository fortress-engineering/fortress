# Data

## Role

The Data preserves exact independent verification inputs for the bounded
native Boolean return comparison.

## Origin

The case authors froze expected results before running the installed native
compiler and interpreter on the bounded authored inputs.

## Semantics

The fixture binds exact authored source and native compiler observations to
returned-value tables and expected supported-scope dispositions.

## Validity

Exact producer and source admission, all expected singleton return
comparisons, and explicit unavailable results are required. The fixture
supplies no project runtime or contract authority.

## Lifecycle

The test replays actual compiler observations under its independently bound
fixture source and adjusts only their request correlation ID.

## Files

### [`native_sensitivity_cases_v1.json`](../_data/native_sensitivity_cases_v1.json)

Records 17 independently authored CPython cases and their observed return
tables or explicit unsupported outcomes. Windows and Linux native receipts
qualify the frozen expectations. The retained Windows compiler frames support
deterministic native body admission in the Rust test.
