# Data

## Role

Frozen finite temporal oracle and its adjudication protocol.

## Origin

Expected meanings were assigned from the written finite partial order and temporal truth table before the production comparator existed.

## Semantics

Nine policy vectors establish exact order labels. Twenty retained temporal axis vectors and all sixteen axis combinations are checked independently; parent-local regressions check their semantic boundaries, merge labels, missingness and controlled cells. An exhaustive test-owned model checks all 81 two-effect policy pairs without deriving expected answers from Fortress verdicts.

## Validity

The protocol binds exact case bytes by SHA-256. Controlled mathematical classification does not establish empirical precision, human validation or whole-program equivalence. No missing-evidence or unsupported case is removed from its declared checks.

## Lifecycle

Retain the original frozen bytes and protocol. Future semantic expansion needs independently specified vectors and versioned changes, preserving prior expectations.
