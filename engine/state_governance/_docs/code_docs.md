# Code

## Role

One pure state-comparison engine.

## Execution

Validate exact inputs, pair stable IDs, compare independent roles, and serialize deterministic results.

## State

Immutable inputs only; no clock, path discovery, evaluator or persistent database.

## Failure Semantics

Typed invalid-input, integrity, cancellation and resource errors. Missing semantic assets remain explicitly noncomparable.

## Files

### [`transition.rs`](../_code/transition.rs)

Public versioned facade and content-addressed canonical boundaries.

### [`model.rs`](../_code/model.rs)

Typed input, output, axis, evidence and authorization-citation records.

### [`validation.rs`](../_code/validation.rs)

Source, authority, vocabulary, path and resource admission checks.

### [`comparison.rs`](../_code/comparison.rs)

Independent axes, finite authored implication, identities and common-authority/merge comparisons.

### [`claims.rs`](../_code/claims.rs)

Original claim, coverage, proof, assurance and finding projections without verdict causation.


### [`identity.rs`](../_code/identity.rs)

Role-partitioned software and complete governing identities keep the original aggregate declaration binding intact. This allows controlled cells to vary authority without falsifying their full repository source identity.

### [`retirement.rs`](../_code/retirement.rs)

Produces comparable retirement v2 from exact original/current state views, stable claim slots, complete source/authority inventories and the existing profile proof assessor. Absence, policy changes and coverage loss remain unresolved; there is no filesystem or grant validation.
