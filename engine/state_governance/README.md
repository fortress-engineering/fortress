# State Governance

## Purpose

Explain changes between two explicitly identified repository states without conflating implementation, intent, governing authority and finding governance.

## Responsibility

Own the single pure state comparator and versioned content-addressed TransitionAnalysis. Pair stable identities before content and preserve noncomparability, original evidence and exact historical meaning.

## Scope

### Includes

Four independent axes, finite effective restrictions, authored guarantee conjunctions, obligations, evaluability, evidence sufficiency, finding dispositions, semantic placement and separately labelled merge-parent comparisons.

### Excludes

Semantic evaluation, filesystem discovery, historical code execution, workflow stores, grant validation, mutation, migration orchestration and deployment policy.

## Guarantees

A changed verdict alone never proves a regression, improvement or code fix. Missing evidence is neither favorable nor unfavorable proof. Only comparable authored promises receive strengthening or weakening labels. Ambiguous identities remain explicit. Authorization references are citations and never validated grants.


The public native entry points are `compare_states`, `compare_states_cancellable`
and `compare_merge`. ComparisonState v1 retains original v1/v2 StateViews or an
explicit partial retained pair, necessary source/authority assets and exact origin
references. TransitionAnalysis v1 uses JCS/SHA-256 and comparator version 1.0.0.
Snapshot Governance supplies current or historical inputs; the comparator has no
filesystem or evaluator dependency. Missing original assets are never reconstructed
as verified. Optional serialized results are derived, digest-bound and nonauthoritative.

Finite exclusions are portable path-prefix selectors. A supported addition that
narrows visibility is a scope exclusion; other scope changes remain noncomparable.
Duplicate semantic occurrences remain ambiguous, while duplicate set members and
malformed/tampered records are refused. Descriptive evidence or obligation changes
never inherit authored-promise strengthening labels. Evidence is integrity-bound,
not automatically producer-authenticated. Legacy transition-v1 retirement observations
withhold resolution when complete comparable retirement proof was not supplied;
the explicit comparable retirement producer emits the separately versioned v2 record.

Comparable retirement reuses the four-axis comparator and original claim slots. Rule/profile/Standard/evaluator/context changes, excluded scope, missing history and reduced coverage remain separate from remediation. Positive resolution requires the existing proof assessor to accept a current proof of the original negative proposition; no favorable conclusion follows from an absent finding ID. Complete comparable identity/source inventories may establish SUBJECT_REMOVED. Neither case grants authorization.

An aggregate claim that remains violated does not supply a per-occurrence absence proof for one disappearing finding. Such residue stays unresolved until its owning evidence supports the narrower proposition. Historical observations and assessments are never rewritten. MIGRATE and ADMISSION must retain original anchors, exact reviewed identity mappings and reintroduction history, and rerun retirement/schema/authorization integration gates after interface changes.

Generic rule-level claims without a narrower authored-policy projection conservatively bind the complete authored intent inventory. Changing that inventory alongside source is not sufficient evidence of remediation; even an unrelated intent change may require explicit review. Incidental JSON formatting is canonicalized, and observed source locations and diagnostic wording remain outside stable finding identity.

Resolution currently admits exact-bound, unconditional native static negative proofs through the existing assessor and its ALL/ANY algebra. Conditional, unsupported, external or report-only support does not acquire retirement authority. Record count and aggregate byte admission are checked before retaining additional retirement output; exhaustion returns an explicit error without a partial favorable result or governance mutation.

**Hypothetical consumers**

OVERLAY supplies exact canonical endpoint facts and retains this Module's four-axis outcomes, incomparabilities and retirement evidence. No candidate verdict alone proves a regression, improvement or resolution. Full physical inventory identity remains separately visible from the semantic comparator's admitted source scope.

The additive `assess_original_findings` port derives exact original finding anchors and uses the same comparable retirement classifier as baseline assessment, without creating a baseline, mutating authority or introducing a semantic evaluator. OVERLAY retains proof dependencies and unresolved outcomes beside proposed findings.

Current capture writers emit comparison-state v2, whose public schema describes StateViews v1–v3 and their existing meanings. Native v1 inputs remain readable without rewriting their hashes. Lossless comparison-projection v1 exposes public owner facts and preserves canonical historical input bytes; it does not authenticate those inputs or replace the comparator.
