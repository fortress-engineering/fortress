# State Governance

## Purpose

Explain changes between two explicitly identified repository states without conflating implementation, intent, governing authority and finding governance.

## Responsibility

Own the single pure state comparator and versioned content-addressed TransitionAnalysis. Pair stable identities before content and preserve noncomparability, original evidence and exact historical meaning.

## Scope

### Includes

Four independent axes, finite effective restrictions, authored guarantee conjunctions, obligations, evaluability, evidence sufficiency, finding dispositions, semantic placement and separately labelled merge-parent comparisons.

### Excludes

Semantic evaluation, filesystem discovery, historical code execution, workflow stores, grant validation, mutation, migration orchestration and deployment policy.

## Guarantees

A changed verdict alone never proves a regression, improvement or code fix. Missing evidence is neither favorable nor unfavorable proof. Only comparable authored promises receive strengthening or weakening labels. Ambiguous identities remain explicit. Authorization references are citations and never validated grants.


The public native entry points are `compare_states`, `compare_states_cancellable`
and `compare_merge`. ComparisonState v1 retains original v1/v2 StateViews or an
explicit partial retained pair, necessary source/authority assets and exact origin
references. TransitionAnalysis v1 uses JCS/SHA-256 and comparator version 1.0.0.
Snapshot Governance supplies current or historical inputs; the comparator has no
filesystem or evaluator dependency. Missing original assets are never reconstructed
as verified. Optional serialized results are derived, digest-bound and nonauthoritative.

Finite exclusions are portable path-prefix selectors. A supported addition that
narrows visibility is a scope exclusion; other scope changes remain noncomparable.
Duplicate semantic occurrences remain ambiguous, while duplicate set members and
malformed/tampered records are refused. Descriptive evidence or obligation changes
never inherit authored-promise strengthening labels. Evidence is integrity-bound,
not automatically producer-authenticated. Retirement records currently withhold any
resolution claim when complete comparable retirement proof was not supplied.
