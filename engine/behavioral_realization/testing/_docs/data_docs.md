# Data

## Role

Frozen bounded workflow source controls and independently authored expected outcomes.

## Origin

Seven controls were authored before native behavioral results; the supplemental controls were authored before compiler adjudication. Neither set derives its expected outcomes from Fortress output.

## Semantics

The corpus distinguishes observed entry-probe traces, static bounded governance expectations, and unknown control evidence. Compiler probes do not prove authorization implementation, runtime coverage or whole-program safety.

## Validity

Each original UTF-8 source is SHA-256 bound. The independent pinned Rust source-control runner verifies expected traces from separately bound instrumented copies. Human adjudication and population accuracy are not claimed.

## Lifecycle

Retain original fixtures and their digests; add separately labeled controls when scope expands. Diagnostic execution records remain separate from certification evidence.
