# Data

## Role

Persist retained research cases and expected outcomes used to verify the immediate parent capability.

## Origin

Maintainers record reviewed source bindings, summary strategies, and expected behavior from the governing requirements and exact dependency sources.

## Semantics

The Data supplies controlled comparison inputs consumed by this Module's verification code. Standard Registry owns the installed catalog authority, and State and Effect Analysis owns its interpretation.

## Validity

Consumers require valid UTF-8 JSON, exact source identities, canonical contexts, explicit unresolved premises, and expected outcomes matching each retained scenario.

## Lifecycle

Maintainers update the retained comparison through reviewed changes alongside its verifier when supported summary semantics or qualified source contexts change.

## Files

### [`operation_summary_qualification_v1.json`](../_data/operation_summary_qualification_v1.json)

Retains the reviewed same-case comparison of authored, source-derived, and hybrid summary strategies, selected source bindings, expected effect facts, and bounded qualification scope. The fixture verifies the advertised installed subset without asserting general dependency effect completeness.
