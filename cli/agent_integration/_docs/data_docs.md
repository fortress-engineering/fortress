# Data

## Role

Defines the portable host capability record.

## Origin

The adapter derives the record from the installed build and its configured route.

## Semantics

The record identifies supported requests, mediated operations, other routes and provider coverage. It carries no authorization.

## Validity

Validate the edition and exact declared scope before using the observation.

## Lifecycle

The record applies to the named host build and configuration.

## Files

### [`host_capability_schema_v1.json`](../_data/host_capability_schema_v1.json)

Defines the first public encoding of host capability facts.
