# Agent Integration Testing

## Purpose

Verify the agent transport and exact trusted invocation boundaries.

## Responsibility

Exercise the installed process, native query parity and the real writer on disposable fixtures. The test reviewer and grant source are controlled inputs outside the fixture repository.

## Scope

### Includes

Transport negotiation, no agent mutation authority, exact review and approval bindings, source drift, cancellation, revocation, and refusal on reused review.

### Excludes

Public host support, live provider authorization, and new governance judgments.

## Relationships

### [Agent Integration](../README.md)

**Types:** `depends_on`, `verifies`

Checks the declared adapter behavior at its ordinary entry points.

### [Engine](../../../engine/README.md)

**Types:** `depends_on`

Supplies the canonical fixture observation, evaluation and transaction adapters.

## Guarantees

Fixtures retain separate source, trust, and execution evidence.
