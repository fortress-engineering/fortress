# Info

## Role

Persist compact computational output whose exact content is required as durable, reviewable repository evidence or ecosystem resolution authority. Large deterministic semantic projections remain Info by role even when their bytes are reconstructed in an execution-local cache instead of retained in Git.

## Production

Cargo produces the resolver lock record from package constraints. The Contract Coherency compiler produces the self-CCG from canonical contracts, recursive containment, standard logic, and supported verification facts. Behavioral Semantics produces the self-BFG from CCG-preserved authored checkpoints and graph semantics. Program Semantics produces the self-PSM from the exact semantic source identity, snapshot-bound Cargo manifests, recursive Module ownership, and structurally parsed Rust source. Semantic Analysis produces its result from the PSM and distributed authored Function Contracts. State and Effect Analysis produces its result from the PSM, Semantic Analysis, distributed State Contracts, and Function Contract v3 state/effect obligations. Architecture Evaluation produces Module semantic-conformance conclusions from explicit Module Contract policy and those exact State/Effect consequences. Information Flow Analysis produces its result from those semantic layers, project-defined ordered facets, and Function Contract v3 flow declarations. Environmental Semantics produces its result from the complete semantic substrate and distributed Module-local Environment Contracts. Behavioral Realization produces the self-Realized BFG from the Intended BFG, the complete implementation-semantic stack, and distributed Behavior Realization Contracts. Certification produces the Evidence Graph, exact-profile Certification result, and Verified BFG from current semantic artifacts, applicable rule results, local unfiltered Rust execution, and Testing-owned verification bindings. The local quality-certificate issuer owns the closed persistence registry, executes the complete canonical gate profile, generates every projection twice, and records each logical path, storage class, byte count, and digest for lightweight hosted freshness verification.

## Semantics

The component resolution index records the CCG-bound mapping from stable Module identity to current portable repository location, stable Rust/Cargo import authority, and explicit Cargo, registry, Rust crate-root, and generated Markdown resolution boundaries. It is derived projection, never a second component inventory. Source Architecture produces Source Artifact Model v1 from Project Filing membership, canonical `code_docs.md` responsibility, exact source bytes, optional observation/PSM references, and the Source Profile registry.

The lock record identifies one exact dependency resolution. The CCG records the deterministic derived semantic ecosystem, its provenance, effective obligations, relationships, support topology, and supported coherency result. The Intended BFG records meaningful Feature-flow intent, Module lanes, boundary crossings, branches, loops, dominators, post-dominators, provenance, and explicit unsupported semantics. The PSM records observed nominal Rust declarations and impls, executable symbols, typed interfaces and supported local expressions, type-directed and residual calls, structured places and mutations, bounded value transfers, call topology, coverage states, and analyzer coherency. The Source Artifact Model records every governed Code file's stable Module-relative identity, current path, exact content digest, authored responsibility, language/profile/archetype status, universal semantic-region coverage, stable PSM/verification references, generated provenance, and structural conclusions without copying the PSM. Semantic Analysis records conservative value domains, fixed-point summaries, contract proof checks, abstract counter-domains, and property-specific uncertainty. State and Effect Analysis records conservative typestate classifications and transitions, direct and transitive effect closure, contract checks, causal evidence, and explicit uncertainty. Module Semantic Conformance records authored policy separately from observed effects, derived capabilities, direct/transitive causal paths, claim-relative coverage, dependency convergence, raw conclusions, and block eligibility. Information Flow Analysis records project-facet classifications, explicit propagation and field-flow summaries, sink checks, abstract counter-labels, trusted-transition diagnostics, and property-specific uncertainty. Environmental Analysis records admissible nondeterministic outcomes, handling status, completion certainty, qualitative timing, retry/idempotency, duplicate delivery, bounded interruption/recovery, deterministic fault scenarios, and property-specific uncertainty. The Realized BFG records exact semantic checkpoint anchors, coverage-aware implementation events, next meaningful checkpoint transitions, intended/realized edge states, proven dominator bypasses, terminal and decision reconciliation, derivation evidence, and unestablished verification obligations. The Evidence Graph records immutable authority, observation, proof, execution, scenario, assertion, and aggregate nodes with dependency-addressed identities. Certification evaluates those nodes using `INVALID > FAIL > STALE > MISSING > PASS`. The Verified BFG preserves intended, realized, and executed/static verification dimensions separately.

Repository persistence follows one explicit authority classification. `info/Cargo.lock` remains tracked ecosystem-maintained resolution authority. The Intended BFG, Environmental Analysis, component resolution index, Evidence Graph, Certification, Verified BFG, and quality certificate remain tracked because they are compact semantic/evidence conclusions or current resolution metadata used by lightweight review and verification. The CCG, PSM, Semantic Analysis, State/Effect Analysis, Module Semantic Conformance, Information Flow Analysis, Realized BFG, and Source Artifact Model are deterministic bulk projections materialized outside the repository; their exact logical paths, byte counts, digests, generator gates, and authoritative-source fingerprint remain bound by the tracked quality certificate, while the Evidence Graph retains their semantic digest dependencies. No artifact becomes authored authority merely because it is tracked, and `info/` placement alone never makes an artifact disposable.

The quality-certificate source fingerprint excludes its own bytes and the complete closed set of fourteen generated semantic/certification projections, but includes every authored contract, source, policy, schema, documentation file, workspace input, and `Cargo.lock`. This avoids self-reference without excluding build-semantic or ecosystem authority. The SHA-256 stamp is tamper-evident and stale-resistant but explicitly not an authenticated signature or release attestation.

## Lifecycle

Cargo regenerates the lock record when dependency inputs change. Maintainers run `python mods/engine/mods/snapshot_governance/code/quality_certificate.py issue .` to execute the complete local gate profile, compile every semantic and certification projection twice, refresh tracked derived evidence, materialize bulk projections in the exact-subject local cache, and issue the final certificate only after all bytes and conclusions agree. Hosted CI runs the corresponding `verify` operation, which checks the current authoritative-source fingerprint, PASS gates, complete artifact registry, tracked evidence bytes, and certificate stamp without requiring the machine-local bulk cache or rerunning Rust.

A clean checkout therefore contains the durable certificate/evidence set but no bulk cache. `artifact-status` reports each absent bulk projection as `MISSING` and exits nonzero; absence is never represented as a current materialization or used as favorable proof. `materialize` first requires a current passing certificate, regenerates each bulk projection twice with repository tooling, checks its certified byte count and digest, and writes it beneath an external cache directory keyed by the exact source fingerprint. The optional `FORTRESS_DERIVED_CACHE_DIR` changes only execution-local placement and is rejected inside the repository. `clean` removes only the explicit Fortress project cache. Old-subject materializations remain historical bytes and report `STALE` for changed authoritative inputs; digest disagreement reports `INVALID`. A missing cache never invalidates the already durable execution/proof evidence in a current certificate, and it never masquerades as materialized output.

Historical evidence remains cryptographically valid about its old subject but is stale for a different subject. Build products and bulk materializations remain transient outside the governed repository, require no network service, and can always be reconstructed from tracked authoritative inputs with the documented repository toolchain.

## Files

### [`Cargo.lock`](../info/Cargo.lock)

Records Cargo-produced exact dependency resolution for reproducible builds under the configured external lockfile path.

### [`behavioral_flow_graph.json`](../info/behavioral_flow_graph.json)

Persists Fortress's canonical derived Intended BFG v1 so local and hosted gates can compare fresh behavioral compilation byte for byte without claiming implementation realization.

### [`component_resolution_index.json`](../info/component_resolution_index.json)

Persists the focused CCG-bound identity-to-current-location projection and registered physical resolution-boundary inventory so pure Module relocation remains measurable and certification can reject stale path projections.

### [`environmental_analysis.json`](../info/environmental_analysis.json)

Persists Fortress's canonical derived Environmental Analysis v1 so local and hosted gates can compare outcome handling, retry/idempotency, bounded recovery, fault scenarios, and uncertainty byte for byte without implying comprehensive fault-tolerance proof.

### [`evidence_graph.json`](../info/evidence_graph.json)

Persists the content-addressed Evidence Graph v1 for the exact certification source, including obligation dependencies and current local execution/scenario evidence without embedding copies of semantic artifacts.

### [`certification.json`](../info/certification.json)

Persists the exact `CERT-FULL-SNAPSHOT-V1` result, certification root digest, obligation statuses, trusted-assertion dependencies, and deterministic status summary.

### [`quality_certificate.json`](../info/quality_certificate.json)

Records the deterministic local-development quality-gate PASS claim, authoritative repository fingerprint, canonical gate commands, complete artifact storage registry, every derived artifact byte count and digest, deterministic audit digest, and a tamper-evident certificate stamp. Its authenticity is explicitly UNVERIFIED because no external trusted signing identity is configured.

### [`verified_behavioral_flow_graph.json`](../info/verified_behavioral_flow_graph.json)

Persists Verified BFG v1 as the evidence-aware projection of Intended and Realized BFG facts, preserving static and executed verification specificity without attributing Feature tests to exact edges absent explicit bindings.
