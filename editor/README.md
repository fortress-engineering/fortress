# Editor

## Purpose

Fortress brings repository evidence and explicitly proposed changes into VS Code's keyboard-accessible developer workflow.

## Responsibility

This Module owns the local desktop client and its installation manifest. It negotiates the installed Fortress service, tracks independent workspace observations, and presents original semantic and governance records through native editor surfaces.

## Scope

### Includes

Saved-source status, doctor, Problems diagnostics, directed Module inspection, paged evidence explanations, schema guidance, unsaved buffer previews, and explicit comparisons.

### Excludes

Remote or virtual repositories, external editor ecosystems, project task execution, certification issuance, authority application, and grant validation.

## Relationships

### [CLI](../cli/README.md)

**Types:** `depends_on`

The installed executable owns canonical observation, transport, explicit analysis, and candidate meaning.

## Guarantees

The extension starts the explicitly configured User Settings executable only in a trusted local workspace. It passes fixed argument lists without a shell. Opening a folder alone starts no Fortress process. Retained observations, current saved source, and unsaved candidates have separate identities. Findings without exact, defensible positions remain browsable as records. Editor actions prepare and display proposals without writing repository files or accepting authority.

For local development installation and the diagnose, preview, and recheck workflow, see [Code documentation](./_docs/code_docs.md).
